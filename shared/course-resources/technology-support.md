# Technology Support

## Boise State Learning Technology Support

- Use the **Info & Resources** button in the main Canvas navigation menu to:
  - Access Canvas help articles
  - Contact the Boise State Help Desk for technical support
- The [University Software page](https://www.boisestate.edu/oit-software/) can provide information
  about Google Workspace, Microsoft Office, DUO, and other Boise State-supported software

---

## Zoom Support

- **If this is the first time you are using Zoom,** follow the Getting Started instructions on the
  [Boise State Zoom page](https://boisestate.zoom.us/) to download and install Zoom
- To learn more about Zoom, visit Boise State's
  [Zoom Basics knowledge base page](https://talk-boisestate.atlassian.net/wiki/spaces/LTS/pages/174293058/Zoom+Basics)

---

## Panopto Support

- Use your **Boise State student login credentials** to set up your free
  [Panopto account](https://boisestate.hosted.panopto.com/)
- See Boise State's
  [Panopto knowledge base page](https://talk-boisestate.atlassian.net/wiki/spaces/LTS/pages/172195852/Panopto)
  to learn more about this software
