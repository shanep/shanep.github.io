# CyBOK Chapters

These are the chapters of the Cyber Security Body of Knowledge (CyBOK) that CS 331 assigns, as
web pages. They read better than the PDF (Portable Document Format) on a phone, and they work with
a screen reader, since the PDF has no tags for headings, tables or reading order.

The text is the book's own, word for word. Every figure has a written description, every table is
a real table, the math is real math, and each chapter ends with the references it cites. Section
numbers match the PDF, so a reading like §10.4 is the same section here.

## Where it comes from

These chapters are from [CyBOK Version 1.2.0](https://www.cybok.org/), edited by Awais Rashid,
Yulia Cherdantseva, Andrew Martin and Steve Schneider. © Crown Copyright, The National Cyber
Security Centre 2026, licensed under the
[Open Government Licence v3.0](http://www.nationalarchives.gov.uk/doc/open-government-licence/).

The pages are made from the PDF by a script, `scripts/cybok/convert.py` in the
[course site's repository](https://github.com/shanep/shanep.github.io). The figure descriptions
and tables are separate files written from the PDF, since a script can't describe a figure.
