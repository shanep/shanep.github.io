## Welcome to CS 331: Computer Security and Information Assurance

This is the first security course most students take, and it is open across departments. The only
assumption is that you have completed one introductory programming course. You will not write a
program from scratch: every lab that involves code gives you a working, commented Python script to
run, change, and explain.

The required text, the Cyber Security Body of Knowledge (CyBOK), is free and already in this
course. No purchase is required.

## Getting Started

1. Review the items in the main course navigation menu, which is available as you work through the
   course.
2. Select **Syllabus** to review the course syllabus and schedule.
3. Select **Modules** when you are ready to begin, starting with **Getting Started**.
