# Projects

All projects are written in C and fork from the same starter repository. Every one
of them must compile and run on **both** GitHub Codespaces and Onyx.

- [Grading Rubric](grading-rubric.md) - universal grading rubric for all projects
- [P0](p0.md) - Compile, Test, Debug
- [P1](p1.md) - Simple Mail Client
- [P2](p2.md) - Reliable Data Transfer
- [P3](p3.md) - Subnetting and Forwarding
- [P4](p4.md) - Packet Capture and Analysis

## Mini-labs

Mini-labs are small, pass/fail, take home exercises done individually. They count
in the Projects group but do not use the starter repository or the project
grading rubric.

- [M1](m1-copilot-cli.md) - GitHub Copilot CLI

## Midterm Alternative

X1 is a take home alternative to the midterm exam, done individually. It counts
in the Midterm group, which keeps the better of the two scores.

- [X1](x1-page-load.md) - Anatomy of a Page Load
