# Grading Rubric

This rubric applies to every project in CS425. Read it once, at the start of the
semester, and refer back to it before each submission.

## Portability

Your code must compile and run on **both** GitHub Codespaces and Onyx. If it builds
on only one of the two you receive a **zero** for the project, even if it works
perfectly on the other. The two machines run different compilers on purpose.
Portable code is a learning objective of this course, not a formality.

## Provided Tests

You are **not** allowed to modify the instructor-provided tests. If you believe a provided test
contains a bug, bring it to office hours. You must pass the tests as written.
