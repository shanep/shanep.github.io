# P3 - Subnetting and Forwarding

**Week 10 · 100 points · about 8 hours · submit in Canvas**

## Overview

You are going to implement the lookup a router performs on every packet it sees:
given a destination address and a forwarding table, find the longest prefix that
matches. Along the way you will write the address arithmetic that CIDR notation
hides, which is the fastest way to stop finding subnet masks mysterious.

Fork the [starter repository](https://github.com/shanep/makefile-project-starter)
using the **Use this template** button and name your copy `cs425-p3`.

::: danger

Your code must compile on **GitHub Codespaces and Onyx**. If it compiles on only
one of them you will receive a zero even if it works on the other.

:::

## Learning Outcomes

- 4.1 Describe the data plane: forwarding, the IP datagram, addressing, and NAT
- 4.4 Subnet an address block with CIDR and compute the resulting ranges
- 7.1 Build code with a build system and run it under a unit test framework

## Task 1 - Address parsing and formatting

Parse `192.168.1.0/24` into a 32 bit address and a prefix length, and format it
back. Reject malformed input rather than guessing at it.

## Task 2 - Subnet arithmetic

Given a block and a prefix length, compute the network address, the broadcast
address, the usable host range, and the number of hosts. Then split a block into
`n` equally sized subnets.

## Task 3 - Longest prefix match

Build a forwarding table from a text file and implement the lookup: for a given
destination, return the entry with the longest matching prefix, or the default
route if nothing matches.

## Task 4 - Testing, coverage, and leaks

Unity tests for every function in `lab.h`, 100% coverage, and a clean
`make leak-test`. Bit manipulation is exactly the kind of code where an off-by-one
survives casual testing, so test the boundaries: `/0`, `/31`, `/32`.
