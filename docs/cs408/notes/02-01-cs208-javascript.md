# 02.01 CS208 JavaScript

## Overview

Below are some links to concepts taught in CS208. Please review them to refresh your memory about
JavaScript.  If any of the concepts are new, please take the time to review them so you can be
prepared to work on your final project. Some frameworks (like ASP.NET) will have very minimal
JavaScript, so you may have to come back and revisit these concepts depending on what tech stack you
select.
