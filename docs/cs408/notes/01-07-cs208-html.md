# 01.07 CS208 HTML

## Overview

Below are some links to concepts taught in CS208. Please review them to refresh your memory about
HTML.  If any of the concepts are new, please take the time to review them so you can be prepared to
work on your final project. You will not be writing raw HTML in this class, you will be writing
templates. All you need to know is the basic structure of HTML docs so you can author the templates
in your selected language.
