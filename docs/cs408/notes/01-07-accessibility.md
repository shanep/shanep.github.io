# 01.07 Accessibility (2 - 4 hrs)

## Overview

This week, we will be learning about accessibility. Making your websites accessible is not only the
right thing to do; it is also required by law. Every web developer needs to have a good
understanding of accessibility basics so they can build awesome websites.
