# Grading Rubric

All programming assignments will be calculated as follows:

- 20% - Repository and submission
  - Your repository was created from the starter template and has all commits **from you** on the
    `master` branch
  - Continuous integration (CI) passes on your last push (`make all`, `make check`, and
    `make leak-test`)
  - Your `README.md` is filled out
  - You submitted the `submission-report.docx` created from your final commit to Canvas
- 50% - Testing
  - Passes 100% of provided tests
- 30% - General Coding Guidelines
  - Criteria detailed below
