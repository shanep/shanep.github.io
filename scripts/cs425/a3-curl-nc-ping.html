Round 2 · nc: be the client yourself

nc knows no protocol at all. It opens a connection and moves bytes, which means you get to be the protocol. That is exactly what P1 asks you to write.

nc -vz onyx.boisestate.edu 22     # something is listening
nc -vz onyx.boisestate.edu 9      # nothing is
PortWhat nc printed, word for wordHow long
22
9

Those are two completely different failures. Telling them apart is most of A4.

Speak HTTP by hand

{ printf 'GET / HTTP/1.1\r\nHost: example.com\r\nConnection: close\r\n\r\n'; sleep 3; } | nc example.com 80

Why the sleep 3? Onyx has nmap-ncat, which closes the connection the moment stdin runs out. Without the sleep, your request goes out and nc hangs up before the reply lands. Run it once without, add -v, and read the bytes sent versus bytes received line.

  1. What was the very first line the server sent back?
  2. Drop the Host: header and run it again. What changed, and why does HTTP/1.1 require it?
  3. Change every \r\n to \n. What does the server do? SMTP has the same rule, and this was the most common bug in P1. You cannot see it in a terminal; you have to know it.

Listen, and be listened to

You are all on one machine, so one of you can be the server. Bind to 127.0.0.1, never 0.0.0.0, and kill it when you are done.

PORT=$((10000 + $(id -u) % 20000)); echo "$PORT"
ss -ltn | grep ":$PORT" || echo "free"
nc -l 127.0.0.1 "$PORT"          # blocks, waiting. Another member: nc 127.0.0.1 <PORT>

Whose port did you connect to, and what did you send? Confirm with ss -ltn that nothing of yours is still listening afterwards.

Round 3 · ping: the one that is not an application tool

Everything above spoke an application protocol. This one does not: ICMP rides directly in IP, and has no ports and no idea what a service is.

ping -c 5 onyx.boisestate.edu       # also try: -i 0.5   -s 1000   -W 2   -w 5   -n   -q
ping -c 3 example.com               # the host you fetched a page from in Round 1

Those two rows contradict each other. That contradiction is the whole point of this round, and of Round 3 in A4.

  1. What layer does ICMP live at, and what does that mean about ports?
  2. Onyx answers ping. Does that prove the SSH server on it is running? Why not?
  3. example.com does not answer ping, and also served you a web page. So what did the failed ping actually tell you? Name at least two different things that could produce that result.
